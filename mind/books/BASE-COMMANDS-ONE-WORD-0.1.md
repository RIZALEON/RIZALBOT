# Base COMMANDS — one word only (0.1)

**HARDCODE (Decider 2026-09-23 · RBOTOOL):** every **base COMMAND** is exactly **one word**. Anything after that word is an **extension** under that base (examples: `bot mint`, `heart status`, `PING -C 3 1.1.1.1`).

**Law:** Offline premier is standard; online is bonus only. Mac · iOS · Android seat lockstep.

**Aliases:** `commands` · `functions` · `?` → same as `help`.

## Proficiency scale

**0–10** = current on-device Rbot proficiency for that base command across the clay seat (Mac SoT · iOS twin · Android twin). Scores are Decider-facing honesty, not marketing.

- **0–2** absent / refuse-only
- **3–4** stub or gated
- **5–6** partial / one-platform strong
- **7–8** solid offline on primary seats
- **9–10** trifecta-strong heartbeat/core
